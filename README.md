# Fabritech

This repository contains the front-end HTML files for the **Fabri-Tech Engineering** website.

Fabri-Tech Engineering provides precision structural steel detailing, 3D BIM modelling, connection design, fabrication support, and industrial structure services across industrial, commercial, and infrastructure sectors.

## Files Included

*   `about.html` - Information about Fabri-Tech Engineering's two decades of structural steel expertise and commitment to accuracy.
*   `contact.html` - Contact information for a detailed scope assessment and competitive quotation.
*   `projects.html` - Portfolio of precision structural steel detailing and BIM modelling projects.
*   `services.html` - Details about structural steel detailing, 3D BIM modelling, connection design, and fabrication support services.
